# Artifacts Directory

This directory stores generated artifacts and temporary output from Access Review operations:

- **output-accessreview-\*.json** - Analysis output logs from Copy-AccessReviewDefinition operations
- **id-to-reopen.txt** - List of Access Review Definition IDs to process
- **Test outputs** - Any temporary test files

**Note:** These files are ignored by git and should not be committed to the repository.
Use this directory for local testing and debugging only.
