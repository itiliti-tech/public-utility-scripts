# public-utility-scripts

General purpose utility scripts.

## Scripts

- `src/find-updated-files/` - Detects updated files by date/time and outputs results for follow-up automation.
- `src/reopen-access-reviews/` - Reopens access reviews from a list of IDs.
- `src/export-disabled-transport-rules/` - Exports disabled Exchange transport rules to JSON and CSV.

See script documentation in `docs/README.md`.
